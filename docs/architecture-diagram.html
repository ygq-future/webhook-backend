自定义 Webhook 转发中心 — 系统架构图

面向邮箱转发（Gmail / QQ / 163）的自定义 Webhook 接收与转发系统 · TypeScript + React 19 + Vite 7 + Bun + Hono

设计稿 v1.0 2026-07-19 部署：Docker 配套文档：design-document.md

① 系统架构总览（组件视图）

单进程服务同时承载 Webhook 接收、Admin API、静态 WebUI 托管与邮件发送；配置持久化到 SQLite（默认）/ PostgreSQL（可插拔）。

接入层（WebUI / API / 接收） 鉴权 转发引擎 转发通道 ForwardChannel 持久化（SQLite/PG） 外部系统

② 数据流（两条主线）

A. 入站 Webhook 转发流（外部触发 → 邮件送达）；B. 管理配置流（管理员在 WebUI 配置资源）。
